# Code of Conduct

We aim for a respectful, evidence-based, and security-conscious collaboration
space. Be constructive, assume good faith, and discuss technical disagreements
without personal attacks, harassment, discrimination, or disclosure of another
operator's private deployment data.

Do not post credentials, player identifiers, IP addresses, save files, backups,
diagnostic logs, private tunnel addresses, or screenshots containing them.
Security concerns follow `SECURITY.md`; reports about conduct can use the same
private maintainer channel until the public project owner publishes a dedicated
moderation contact.

Maintainers may remove content or restrict participation when this code of
conduct or the repository safety boundaries are breached. This lightweight
policy is intentionally focused on the risks of operating a game server; it
does not replace the hosting platform's own rules.
