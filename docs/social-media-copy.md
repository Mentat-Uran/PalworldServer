# 社媒宣传文案

## 主文案

自己搭 Palworld 专服，不必再记一堆 Docker、RCON 和 PowerShell 命令。

Palworld Server Toolkit 是一个运行在 Windows 本机的开源服务器控制台：把服务器启动、停止、设置、保存、备份、日志、玩家管理，以及 Docker / Windows 原生运行时切换，集中到一个清晰的本地面板里。切换前自动创建快照，管理接口默认只开放给本机，存档仍由你自己掌握。

第一次部署也很简单，而且不要求先安装 Docker：下载 MSI 安装包或解压便携 ZIP，准备好项目目录后，双击 `install-windows-server.bat`，一键开始下载 SteamCMD 和约 5 GB 的 Windows 原生服务端文件；下载完成后双击 `start-windows.bat`，再打开桌面应用选择项目目录。首次下载需要等待，但窗口会显示进度，已有文件会复用。两种包功能相同，区别只是“安装使用”或“解压即用”。

它不是云托管，也不会替你租服务器、上传世界存档或强行开放公网端口；你保留数据和控制权，工具负责把复杂操作变得更直观。

项目地址：<https://github.com/Mentat-Uran/PalworldServer>

## 短版

把 Palworld 专服管理从“记命令”变成“看面板”。没有 Docker 也能用：双击 `install-windows-server.bat` 开始下载 Windows 原生服务端，下载完成后双击 `start-windows.bat`，再打开控制台选择项目目录。工具支持保存、备份、日志、玩家管理和安全切换，并提供 MSI 安装包与解压即用的便携 ZIP。数据留在自己的电脑，Web Console 默认只允许本机访问。
